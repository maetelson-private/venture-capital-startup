# hcdb 가 못 잡는 초기 헬스케어 기업 — 새 수집 원천 조사 (2026-11-17)

코드는 붙이지 않았다. DB 는 읽기 전용 대조만 했다.

## 0. 요약

- **찾을 대상:** 아래 네 유형이다. 대상 조건은 설립 3년 이내(투자 이력 없으면 5년), 국내, 예비창업팀 포함.
  - A. 임상가(의사·간호사·약사 등) 창업
  - B. 병의원·약국·요양기관 운영 소프트웨어
  - C. 보험사·기업이 돈을 내는 회사
  - D. 스스로 '기술 스타트업'이라 부르지 않는 헬스케어
- **확인한 원천:** 직접 열어 명단까지 본 원천은 22곳이다(A 5, B 6, C 6, D 5). 열지 못했거나 명단을 확인하지 못한 곳은 '미확인'에 따로 뒀다.
- **상위 5 (신규 비율 × 통과 비율 × 난이도):**
  1. KHF 겨자씨키움센터 특별관 (A)
  2. 심평원 보건의료빅데이터·AI 창업경진대회 (A)
  3. 투비닥터 창업경진대회 (A)
  4. KHIDI 고령친화 업체검색 (D)
  5. REHA 홈케어·재활·복지전시회 참가업체 (D)
- **B·C 는 상위 5에 없다.**
  - B: 의료·약업 전문지에서 약국·요양 SaaS 처럼 DB 에 없는 회사가 나온다. 다만 대부분 업력이 길다. 구조화된 원천 중에는 KIMES API(점수 0.17)가 가장 낫다.
  - C: 초기 회사는 이미 DB 에 대부분 있다(KB스타터스 표본 9/10, 삼성 C-Lab 헬스케어 4/5). 새 시드보다 기존 기업에 지불자 근거('보험사·기업 고객')를 붙이는 보강 원천으로 쓰는 편이 맞다.
- **점수 공식은 원천 규모를 반영하지 않는다.**
  - 1~3위는 연 5~16팀 규모의 작은 원천이다.
  - 연간 새로 들어올 통과 기업 수로 보면 순서가 달라진다: 사회적기업 CSV, KHIDI, REHA, KIMES 가 앞선다(§5-2).
- **판정 불가가 많다.** 새 회사는 설립일을 찾지 못한 경우가 많아, 통과 비율은 판정 가능한 표본만으로 계산했다. 특히 D 유형 원천은 설립일을 주지 않는다. 그래서 국민연금·국세청 조인이 붙어야 실제 통과율이 나온다.
- **덤으로 나온 발견:** 기존 `news` 명령의 Google News RSS 호출이 robots.txt 를 어긴다(§7).

배경 수치: 지금 DB 의 롱리스트(하드필터 통과 + 범위 포함)는 817곳이고, 그중 투자 이력 없는 곳이 639곳이다. 요청서에 적힌 524·324곳 이후로 범위 재판정이 있어서 숫자가 달라졌다.

## 1. 방법

- **조사 방식:** 유형별로 먼저 '이 유형의 창업자가 회사를 만들 때 남기는 흔적'을 적었다. 그다음 흔적마다 실제 원천을 찾아 열었다. robots.txt 는 해당 경로까지 확인했고, 이용약관은 수집 금지 조항이 있는지 봤다.
- **표본 대조:** 원천마다 실명 10곳(공개된 이름이 그보다 적으면 전부)을 뽑아 `companies`·`company_aliases` 와 대조했다. 대조는 `norm_name` 정규화 후 완전일치로 했다.
- **표기 차이 재확인:** 완전일치만으로는 표기 차이를 놓친다. 그래서 상위 원천의 신규 판정은 유사도 매칭(부분 포함, 유사도 0.85 이상, '코리아·글로벌' 접미어 제거)으로 다시 봤다.
  - 메디벤스↔메디밴스, 사운더블헬스코리아↔사운더블헬스, 멜라누아↔멜라누아(Melanoir) 3건이 실제로는 기존 회사였다. 보정해서 반영했다.
- **통과 기준:** 국내이면서 다음 중 하나.
  - 설립이 2023-11-17 이후
  - 투자 이력이 없어 보이면 설립이 2021-11-17 이후
  - 예비창업팀
- **통과 판정 방식:**
  - DB 에 있는 회사는 DB 의 하드필터 값을 그대로 썼다.
  - 새 회사는 원천에 나온 설립일이나, 공개 기업정보를 한 번 검색해 판정했다.
  - 그래도 못 찾으면 '판정 불가'로 두고, 통과 비율은 판정 가능한 표본만으로 계산했다.
- **난이도 계수:** 쉬움 1.0 / 보통 0.6 / 어려움 0.3. 약관이나 robots 때문에 수기로만 모을 수 있으면 '보통' 이하로 매겼다.
- **제외한 곳:** THE VC·혁신의숲처럼 투자받은 뒤에 올라오는 곳, LinkedIn. 로그인·결제가 필요한 곳은 그 사실만 적고 우회하지 않았다.
- **확인 방법:** 원천 조사는 유형별로 나눠 진행했다. 상위 원천은 직접 다시 열어 확인했다(§6).

### 5-2. 상위 5 추천과 주의점

1. **KHF 겨자씨키움센터 특별관 (A)**
   - 장점: 의사·간호사가 병원 안에서 만든 팀이 직함과 함께 실명으로 나오는, 거의 유일한 정적 페이지다. robots 가 전체를 허용하고 약관 제한도 없다.
   - 함께 얻는 것: KHF sitemap 에 2022~2026 특별관 약 25쪽이 있어, 파서 하나로 A2·A3 와 병원 R&D관·대학 공동관까지 같이 얻는다.
   - 주의: 연 13팀 정도로 작고, 대부분 아직 법인이 아니다. 4팀은 기존 협력사와 공동개발하고 있어, 실제 투자 대상이 협력사일 수 있다. 겨자씨 데모데이 수상팀(메디게이트 기사, 5팀)도 같은 성격이다.
2. **심평원 보건의료빅데이터·AI 창업경진대회 (A)**
   - 장점: 아이디어 부문에 예비팀이 많다.
   - 주의:
     - 기사에는 16팀 중 6~8팀만 나온다. 심평원 보도자료 첨부에 전체 명단이 있는지 먼저 확인해야 한다.
     - 창업자가 임상가인지는 알 수 없어 A 적합도는 중간이다.
     - 표본 8곳 중 3곳은 판정 불가다.
3. **투비닥터 창업경진대회 (A)**
   - 장점: 의대생·전공의 예비팀이라 A 에 가장 잘 맞는다.
   - 주의: 연 4~5팀뿐이고, 유니콘팩토리 약관 때문에 자동 수집이 안 된다. 기존 예비·초기 창업 뉴스 검색어 세트에 '투비닥터'를 넣는 정도가 맞다.
4. **KHIDI 고령친화 업체검색 (D)**
   - 장점: 121곳을 요청 한 번으로 받는다. 표본이 모두 제품 회사(복지용구·시니어 용품)다.

### 5-3. B·C 에 대한 판단

- **B:** 구조화된 공개 원천 중에서는 KIMES API(사업자번호 포함 → 국세청 대조가 바로 됨)가 유일하게 쓸 만하다.
  - B 의 '제도 흔적'(청구SW 인증, 장기요양 청구, 실손24 EMR)은 공개 명단이 없다.
  - 약국·요양 SaaS 는 전문지 기사에서 처음 나오지만 대부분 업력이 길다. DB 에 없는 이유는 '아직 안 봤기 때문'이라기보다 '너무 오래돼서 필터에 안 걸릴 회사'에 가깝다.
  - 2026-12-24 시행되는 비대면진료 중개업 신고 목록이 공개되면 다시 볼 만하다.
- **C:** "그런 회사가 기록되는 곳을 안 봐서 적다"는 가설은 C 에서는 맞지 않았다.
  - 보험사·기업 협업 명단에 나오는 초기 헬스케어 회사는 이미 DB 에 있었다(KB 9/10, 삼성 헬스케어 4/5, 뉴스 7/10).
  - 롱리스트에서 C 가 적어 보이는 것은 지불자 근거가 없어서(지불자 미상 96%)다.
  - 그래서 KB스타터스 JSON(쉬움)과 C-Lab 명단은 새 시드보다 **기존 기업에 '보험사·기업 고객' 근거를 붙이는 보강 원천**으로 쓰는 편이 효과가 크다. 예: 리소리우스·마고·리브라이블리·메디아크.

## 7. 덤으로 나온 발견

1. **기존 `news` 명령의 Google News RSS 호출이 robots.txt 를 어긴다.**
   - `hcdb/sources/news.py` 의 `search_google_rss()` 가 `check_robots=False` 로 `news.google.com/rss/search` 를 부른다.
   - robots.txt 는 `/rss` 를 허용하지 않고, 피드에도 개인·비상업 용도로만 쓰라고 적혀 있다.
   - README 의 크롤링 매너(robots 준수)와 어긋난다. NAVER 키가 없을 때의 대체 경로라서, NAVER API 로만 돌리는 편이 맞다.
2. **이름 대조가 표기 차이에 약하다.**
   - '코리아·글로벌' 접미어나 모음 변형(벤/밴) 때문에 같은 회사가 새 회사로 들어올 수 있다. 원천을 붙이기 전에 `find_company` 의 정규화를 보강해야 신규 비율이 부풀지 않는다.
3. **일부 매체가 AI 봇을 이름으로 막는다.**
   - 데일리팜·벤처스퀘어·sateconomy 가 robots 에서 ClaudeBot·GPTBot·anthropic-ai 를 막는다.
   - hcdb 의 UA 는 `hcdb-research` 라 문자 그대로는 해당하지 않는다. 다만 수집에 LLM 을 쓰는 이상, 이 매체들의 본문은 사명 추출까지만 쓰고 본문 재배포는 하지 않는 편이 안전하다.
4. **D 유형 원천은 모두 설립일을 주지 않는다.**
   - 하드필터를 적용하려면 국민연금 가입사업장(`nps`, 이미 있음)이나 국세청과 이름 대조로 설립 연도를 근사해야 한다.
   - 유치사업자(2,947곳)는 이 조인 없이는 쓸 수 없다.
